# Revive Auto Works

> **Driven By Excellence** — Expert automotive repairs, diagnostics, servicing and vehicle maintenance.

A premium single-page conversion landing page for Revive Auto Works. Every CTA redirects to WhatsApp — no forms, no email capture, just direct conversations.

## Tech Stack

- **Framework**: Next.js 16 (App Router) + TypeScript 5
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Manrope

## Features

- Sticky navbar (transparent on top, solid on scroll)
- Full-screen cinematic hero with overlay
- Trust strip with key stats
- Six service cards with hover glow
- Two-column About section with image reveal
- "Why Choose Us" feature grid
- 4-step process timeline
- Bold CTA section with WhatsApp + Call actions
- Footer with contact details and quick links
- Sticky mobile WhatsApp button (thumb-friendly)
- SEO: Local Business (AutoRepair) JSON-LD schema, OpenGraph, Twitter metadata
- Fully responsive, dark mode by default
- WCAG-friendly: semantic HTML, ARIA labels, keyboard accessible

## Brand System

- **Primary**: Deep Automotive Blue
- **Accent**: Electric Blue `#1E90FF`
- **Base**: Near Black `#090a0f`
- **Surface**: Charcoal `#12141c`
- **Text**: Soft White `#f3f4f6`
